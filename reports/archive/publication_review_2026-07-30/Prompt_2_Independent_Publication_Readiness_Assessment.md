# Prompt 2 --- Independent Publication Readiness Assessment

You are **not** the author of this research.

You are an independent senior researcher and experienced reviewer for
peer-reviewed conferences in Computer Vision, Machine Learning,
Intelligent Transportation Systems, Driver Monitoring Systems, Embedded
AI, and Applied Artificial Intelligence.

Your responsibility is **not** to help me.

Your responsibility is to determine whether this research deserves
publication.

Assume the paper should be **rejected unless sufficient scientific
evidence convinces you otherwise**.

Be objective. Be skeptical. Do not inflate scores. Judge only the
evidence.

------------------------------------------------------------------------

# Inputs

Read:

-   Independent Scientific Research Review
-   EXP-005 Report
-   EXP-005 Audit
-   Root Cause Analysis
-   Research Evidence Package
-   Supporting reports and experiment artifacts

Treat the Internal Scientific Review as an evidence summary, but
independently verify important conclusions.

------------------------------------------------------------------------

# Literature Review

Search recent scientific literature (preferably from the last five
years).

Review work related to:

-   Driver drowsiness detection
-   Computer vision driver monitoring
-   Multi-cue fatigue detection
-   Temporal fatigue modeling
-   Event-level evaluation
-   Geometry-based fatigue detection
-   Hybrid rule-based + deep learning systems
-   Edge AI driver monitoring

Compare:

-   research problem
-   novelty
-   methodology
-   datasets
-   evaluation protocol
-   statistical quality
-   reproducibility
-   practical contribution

------------------------------------------------------------------------

# Independent Comparison

Determine whether this work is:

-   Reproduction
-   Incremental
-   Moderately novel
-   Significantly novel

Support every conclusion using published literature.

------------------------------------------------------------------------

# Scientific Contribution

Evaluate:

-   What is genuinely new?
-   What has already been done?
-   Which contributions are supported by evidence?
-   Which claimed contributions are unsupported?

------------------------------------------------------------------------

# Publication Readiness

Judge whether this work is suitable for submission to a **mid-tier
peer-reviewed conference**.

Evaluate against realistic IEEE/ACM mid-tier standards rather than only
top-tier venues.

------------------------------------------------------------------------

# Strengths

List the strongest aspects of the research.

------------------------------------------------------------------------

# Weaknesses

Separate weaknesses into:

-   Critical
-   Major
-   Moderate
-   Minor

Explain whether each weakness:

-   prevents publication,
-   can be fixed through writing,
-   or requires additional experimental evidence.

------------------------------------------------------------------------

# Additional Experiments

Recommend new experiments **only if their absence makes the paper
scientifically incomplete**.

For every recommended experiment explain:

-   why it is necessary,
-   whether it is mandatory or optional,
-   whether submission is still reasonable without it.

------------------------------------------------------------------------

# Conference Suitability

Recommend realistic conferences.

Explain:

-   suitability,
-   strengths,
-   weaknesses,
-   expected acceptance prospects.

------------------------------------------------------------------------

# Reviewer #2 Simulation

Write a complete reviewer report including:

-   Summary
-   Strengths
-   Weaknesses
-   Questions
-   Recommendation

------------------------------------------------------------------------

# Final Decision

Choose exactly one:

-   Reject
-   Weak Reject
-   Borderline
-   Weak Accept
-   Accept

Explain the reasoning.

------------------------------------------------------------------------

# Final Recommendation

Answer:

1.  Is this work publishable in a mid-tier peer-reviewed conference?
2.  If not, why not?
3.  What is the biggest scientific weakness?
4.  Are additional experiments required?
5.  If yes, specify exactly which experiments and why.
6.  If no, explain why the current evidence is sufficient.
7.  If you were my PhD advisor, would you recommend:
    -   Submit now
    -   Revise the manuscript only
    -   Perform additional experiments before submission

------------------------------------------------------------------------

# Deliverable

Write:

`reports/PUBLICATION_READINESS_ASSESSMENT.md`

Support every conclusion using either:

-   evidence from the project documentation, or
-   evidence from published scientific literature.

If evidence is insufficient, explicitly state that instead of guessing.
